# W1.3 P3 C7 — V4 propagation/abort proof (ODC-031)

**Property (decision-3 / C4 addendum).** The V4 `GetListForBlock` throw
(`deterministicgms.cpp:899`, `"No gamemaster list data found for block <h> ...
Possible corrupt database."`) **propagates to the top of the stack and aborts** — it is
**not caught or converted to a consensus reject**, and the C4 generate-time
skip-not-throw does **not** swallow it (the skip at `ptx_dkg_pending.cpp:64` keys only on
`CheckPTXDKGTx` returning `false` with a `CValidationState` reject; a *throw* never reaches
that `return false`).

**V4 is a corruption-only guard.** It is unreachable in steady-state consensus: once the
tip list is built, `GetListForBlock` caches every active-chain diff down to the snapshot
(`:864`, `:877`), so any anchor `≤ tip` on the active chain is cache-served and never
re-reads disk. The throw fires only on a **cold cache over an on-disk-corrupt evodb** — i.e.
a load/restart. It guards local DB corruption, not adversarial input; no attacker-controlled
input reaches it (V1–V3 guarantee the anchor is an active-chain block whose list is present
by construction on a healthy node).

Proven by: source-trace (primary) + confirmatory smoke (observed) + stub→RED (falsification).
